# 04｜RAWGraphs 源码与图表风格研究

研究对象为 RAWGraphs App 的 `master` 提交 `48c3b2ee9ff412721a2c99c7bed38e734b3fa534`。应用包版本为 2.1.0。仓库定位是把表格数据、图形定义、视觉参数和可编辑输出连成一条工作流。

## 阅读结论

| 发现 | 对信息可视化设计的作用 |
| --- | --- |
| 图表通过 `dimensions` 声明接受的字段、数据类型及必需性 | 从任务和字段形态选图，减少用视觉风格倒推数据结构 |
| 原输入、解析结果、类型化数据、映射和风格参数分开 | 能定位问题发生在数据、统计还是排版 |
| 同一套数字可换用不同图表，但要重新明确聚合及图形单位 | 一组数据可以服务不同阅读问题，改图时要重新做判断 |
| SVG 保存图形结果，项目文件保存源数据和映射 | 形成可追溯的工作底稿与展示稿，而非只留下最终截图 |
| 内置注册表包含 32 个图表，样例目录含 27 个文件 | 图表数量、样例文件数量与课程里的表现形式数量各自统计 |
