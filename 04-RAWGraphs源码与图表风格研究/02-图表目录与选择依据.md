# 02｜32 个内置图表与选择依据

本表依注册顺序列出锁定版本的可选图表。字段名、类型及必需性读取自安装后的图表定义。表内选择与读图提示为本文分析。星号 `*` 表示必需，⁺ 可映射多个字段。实际轴向、标记和样式仍取决于图表设置。 [注册表](https://github.com/rawgraphs/rawgraphs-app/blob/48c3b2ee9ff412721a2c99c7bed38e734b3fa534/src/charts.js) · [锁文件](https://github.com/rawgraphs/rawgraphs-app/blob/48c3b2ee9ff412721a2c99c7bed38e734b3fa534/package-lock.json) · [图表包仓库](https://github.com/rawgraphs/rawgraphs-charts)

## 从数据结构选图

| 数据结构 | 可先试的图表 | 先确认的问题 |
| --- | --- | --- |
| 日期、组、数值 | Line、Horizon、Streamgraph、Bump | 要看量值、构成还是名次？ |
| 主体、开始、结束 | Gantt | 相邻记录是接续区间还是可重叠区间？ |
| 逐层类别、权重 | Treemap、Sunburst、Dendrogram | 类目层级是否互斥，权重能否相加？ |
| 来源、去向、权重 | Sankey、Chord、Arc | 连线对应实际过程、调拨或关系？ |
| 多列同一记录上的类别 | Alluvial | 每条记录是否可以在各阶段对应？ |
| 两个离散维度与值 | Matrix Plot | 单元如何聚合，空白是否代表缺测？ |
| 双数值观测点 | Bubble、Hexagonal binning、Contour | 逐点查看还是寻找分布模式？ |
| 原始数值与分组 | Beeswarm、Box、Violin | 当前重点是单个记录、统计摘要还是分布形态？ |

## 逐图目录

| 序号 | 图表 | 字段角色与类型 | 适用问题与读图限制 |
| ---: | --- | --- | --- |
| 1 | Alluvial Diagram | Steps*⁺≥2（数值／日期／文本）、Size（数值） | 比较各步骤类别如何组合。没有稳定跨期实体时，用“类别组合”描述流带。 |
| 2 | Arc Diagram | Source node*（数值／日期／文本）、Target node*（数值／日期／文本）、Size（数值） | 沿基线展平网络；排序决定弧线交叉及读图重心。 |
| 3 | Bar chart | Bars*（数值／文本／日期）、Size（数值）、Color（数值／文本／日期）、Series（数值／文本／日期） | 用共同基线比较量值；确认同类别多行的聚合方式。 |
| 4 | Multi-set bar chart | Sets*（数值／文本／日期）、Size*⁺（数值）、Series（数值／文本／日期） | 并列比较多个指标或系列，确保单位可比。 |
| 5 | Stacked bar chart | X Axis*（数值／文本／日期）、Size*⁺（数值）、Series（数值／文本／日期） | 比较总量及构成；中间层难直接比大小，归一化应明确分母。 |
| 6 | Beeswarm plot | X Axis*（数值／日期）、Size（数值／日期）、Color（数值／文本／日期）、Label⁺（数值／日期／文本）、Groups（数值／文本／日期） | 用点的散开减少重叠；避让方向仅用于排版。 |
| 7 | Box plot | Y Axis*（数值）、Groups（数值／日期／文本）、Color（数值／文本／日期） | 概括中位数和分布，不用箱线掩盖样本数或多峰性。 |
| 8 | Bubble chart | X Axis*（数值／日期）、Y Axis*（数值／日期）、Size（数值）、Color（数值／日期／文本）、Connection by（数值／日期）、Label⁺（数值／日期／文本）、Series（数值／日期／文本） | 用平面位置比较两个数值，面积表达第三量；控制遮挡。 |
| 9 | Bumpchart | X Axis*（数值／日期）、Size（数值）、Ranking（数值）、Streams（数值／文本／日期）、Series（数值／文本／日期） | 追踪名次升降；名次差和原数量差分别解释。 |
| 10 | Calendar heatmap | Date*（日期）、Color（数值／文本／日期） | 用周历位置和色阶看周期；空值与零值使用不同样式。 |
| 11 | Chord Diagram | Source node*（数值／日期／文本）、Target node*（数值／日期／文本）、Size（数值） | 环内连带表达组间关系；交叉太多时分组或改邻接矩阵。 |
| 12 | Circle Packing | Hierarchy*⁺（数值／日期／文本）、Size（数值）、Color（数值／日期／文本）、Label⁺（数值／日期／文本） | 强调包含和体量；相近圆面积的精确比较仍需数字。 |
| 13 | Circular dendrogram | Hierarchy*⁺（数值／日期／文本）、Size（数值）、Color（数值／日期／文本）、Label⁺（数值／日期／文本） | 环状展开多级树；角度与枝长按布局或图例解释。 |
| 14 | Contour plot | X Axis*（数值／日期）、Y Axis*（数值／日期） | 看二维点的密度轮廓；带宽和阈值影响轮廓尺度。 |
| 15 | Convex hull | X Axis*（数值／日期）、Y Axis*（数值／日期）、Groups（文本）、Label⁺（数值／日期／文本） | 凸包显示极端点包围的范围；边界并非置信区间。 |
| 16 | Linear dendrogram | Hierarchy*⁺（数值／日期／文本）、Size（数值）、Color（数值／日期／文本）、Label⁺（数值／日期／文本） | 读树分支；层级列只是包含关系，未给距离时枝长属布局。 |
| 17 | Gantt chart | Start date*（数值／日期）、End Date*（数值／日期）、Groups（文本）、Color（文本） | 首尾位置体现时间区间；核对日期格式、时区和结束日口径。 |
| 18 | Hexagonal binning | X Axis*（数值／日期）、Y Axis*（数值／日期） | 把二维点聚入六边形；格密度不能自动说明比率。 |
| 19 | Horizon graph | x axis*（数值／日期）、y axis（数值）、Groups（数值／日期／文本） | 以压缩的色带显示多条序列；读者需要清楚的色阶与参考线。 |
| 20 | Line chart | X Axis*（数值／日期）、Y Axis*（数值／日期）、Lines（数值／文本／日期）、Color（数值／文本／日期）、Series（数值／文本／日期） | 突出连续顺序与变化；对缺失区间、时间尺度和系列标签明确说明。 |
| 21 | Matrix Plot | X Axis*（数值／日期／文本）、Y Axis*（数值／日期／文本）、Size（数值）、Color（数值／日期／文本）、Label⁺（数值／日期／文本） | 两轴定义单元，色或大小承载第三变量；明确缺失单元。 |
| 22 | Parallel coordinates | Dimensions*⁺（数值／日期）、Color（数值／日期／文本） | 看多指标轮廓；各轴量纲、方向和归一化须可读。 |
| 23 | Pie chart | Arcs*⁺（数值）、Series（数值／日期／文本） | 用于共同分母的少量构成；接近的角度建议配数字。 |
| 24 | Radar Chart | Spokes*⁺≥3（数值）、Color（数值／文本／日期）、Series（数值／文本／日期） | 看标准化多指标轮廓；轴排序会改变形状。 |
| 25 | Sankey Diagram | Source node*（数值／日期／文本）、Target node*（数值／日期／文本）、Size（数值） | 比较来源与去向的量值；边宽对应权重，注明单位。 |
| 26 | Slope chart | Source*（数值／日期）、Target*（数值／日期）、Label（数值／日期／文本）、Color（数值／日期／文本）、Series（数值／文本／日期） | 突出两个状态之间的变化；端点应共享指标及尺度。 |
| 27 | Streamgraph (area chart) | X Axis*（数值／日期）、Size（数值）、Streams（数值／文本／日期）、Series（数值／文本／日期） | 看多个系列的总体演变与相对构成；浮动基线使非边缘系列难精确读值。 |
| 28 | Sunburst diagram | Hierarchy*⁺（数值／日期／文本）、Size（数值）、Color（数值／日期／文本）、Leaf label⁺（数值／日期／文本） | 以环层表达层级与份额；较薄子类需另外标注。 |
| 29 | Treemap | Hierarchy*⁺（数值／日期／文本）、Size（数值）、Color（数值／日期／文本）、Label⁺（数值／日期／文本） | 以矩形面积表达可加权重；分类边界和重复计数须复核。 |
| 30 | Violin plot | Y Axis*（数值）、Groups（数值／日期／文本）、Color（数值／文本／日期） | 展示估计密度；带宽、单位及样本数影响跨组读法。 |
| 31 | Voronoi Diagram | X Axis*（数值／日期）、Y Axis*（数值／日期）、Color（数值／日期／文本）、Label⁺（数值／日期／文本） | 按点生长最近邻区域；单元面积受点密度与裁切边界共同影响。 |
| 32 | Treemap (Voronoi) | Hierarchy*⁺（数值／日期／文本）、Size（数值）、Color（数值／日期／文本）、Label⁺（数值／日期／文本） | 用嵌套不规则多边形表达权重；查面积、标签与可比性。 |
