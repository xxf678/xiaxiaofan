# 04｜基础数据集构建

先说明**一行代表什么**，为每行设置稳定 ID。**一列只记录一种字段，每个单元格只存一个值**。字段可存名义类别、量化值、图像引用或一段文本。

| 字段名示例 | 类型 | 一个单元格存什么 |
| --- | --- | --- |
| record_id | 文本 | 一条记录的 ID |
| name | 名义 | 一个对象名称 |
| latitude | 数值 | 一个纬度 |
| longitude | 数值 | 一个经度 |
| gdp_value | 数值 | 一个 GDP 数值，币种和量级记入字典 |
| image_ref | 图像引用 | 一个图像 ID、路径或 URL |
| description | 文本 | 一段对应该记录的说明 |

多张图用「记录 ID＋图像引用」另建关联表，一行对应一张图。量值与单位分开，日期精度和空值含义写入数据字典。字段只是结构示例，按实际选题保留需要的列。

提交物为清洗后的 CSV 或表格及数据字典。字典记录字段名、定义、类型、单位、数据来源、缺失规则和允许值。
