# 02｜主题内容分析

## 与大模型共同判断

把调研结论、读者问题和三至五行真实样例交给大模型。请它区分**数据逻辑、表现标签、视觉风格**，提出有依据的候选方案并指出所需补充的数据。将对话结论和最终选择记录在下表。

| 判断层 | 可比较的选项 | 最终选择及理由 |
| --- | --- | --- |
| 基础数据逻辑 | 编年型、层级型、编目型、字母表型、地理图形 | |
| 主表现与辅助标签 | 时间轴型、文字／列表型、图片式、词云等 | |
| 视觉风格 | 平面图形、照片主导、图文混合等 | |
| 设计方式 | 如有系统性的象形符号转译，可考虑 ISOTYPE | |

可直接使用下面这段提问。

> 我的选题是【主题】，读者希望了解【问题】。现有数据字段为【字段】，样例为【内容】。请提出两种有数据依据的方案，分别说明基础数据逻辑、主表现、辅助标签和视觉风格。说明每种方案怎样回答读者问题、还需补哪些数据，并给出取舍理由。缺失信息请标为待核验。
