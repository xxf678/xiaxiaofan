# 03｜数据搜集

| 资料类别 | 归档位置 | 记录要点 |
| --- | --- | --- |

| 来源 ID | 资料名称 | URL 或文件名 | 可提取字段 | 范围与来源限制 |
| --- | --- | --- | --- | --- |
| | | | | |

资料清单与原始记录分开保存。对同一指标的不同来源核对年份、单位和定义，注明最终采用的来源。
