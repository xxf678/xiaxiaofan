# 04｜风格转化与制作方法

## 用本库的 A–E 拆 RAWGraphs

| 维度 | 制作时的记录 | 读图时的核对 |
| --- | --- | --- |
| A 数据逻辑 | 一行代表什么，主键与关联键，时点、层级、类目或地理参照 | 视觉连接是否真的对应数据关系 |
| B 统计图形 | 单位、分母、聚合、空值、不展示范围及排序规则 | 标题所称“多”“快”“占比”是否有对应尺度 |
| C 视觉编码 | 位置、长度、面积、线宽、颜色、图符各承载什么 | 强调色有没有误导成第二份数值，文字是否可读 |
| D 信息架构 | 数据表、图例、正文图注、补充数值表之间的层次和关联 | 能不能在图上找到同一对象、分组和出处 |
| E 视觉叙事 | 核心问题、首读锚点、局部解释、回到总览的路径 | 可否一句话复述主题，再用图表和来源核验 |

## 有数据才决定映射

1. **辨认问题。** “地方传统工艺有哪些类型”适合分类对照，“某技艺的两段传承时间如何接续”适合时间区间。“地区之间哪类产品流通最多”需要来源、去向和量值。
2. **建最小数据表。** 先写出一行代表什么，再准备日期、类别和数值。颜色字段可以是实际类别，也可以由编辑规则指定为注释强调，两者的图例分别处理。
3. **先画统计底图。** 以最少必需映射出图，从样本中手算少量记录，与画面标值、默认聚合和分母核对。遇到混单位或日期误判先改数据。
4. **再做展板版式。** 将定稿 SVG 导入设计软件，统一字体、注释线、图例和留白。局部插画服务对象识别，必要时用数字或补表支撑细读。
5. **保存可核验的版本。** 数据、项目文件、基础 SVG、编辑后的 SVG 或 AI 及最终展示图采用同一主题命名；用短注记录数据来源、图型、映射与改动。

## 与现有项目的衔接

| 项目或条目 | 可以尝试的方案 | 前提与边界 |
| --- | --- | --- |
| 徽州三雕「雕纹寻徽」 | Matrix Plot 以工艺为一轴、纹样类别为另一轴，统计已确认的图例；将热点或纹样小图作为解释层 | 先建立图例 ID，区分同一纹样在多个载体上的记录。没有样本全量时把图标题写成“已收录图例” |
| 「荷塘里·陶辛莲子」 | 对包装层级做 Treemap 数据实验，或用带注释的爆炸图表现组件与配件 | 组件面积须由可加的重量或材料面积支持。结构拆解更适合已有三视图和爆炸图，数值未提供时可用示意说明 |
| 编年型和时间轴型文档 | 用 Gantt 解释历时，用折线解释随时间变化的量值，用排名图追名次 | 日期尺度、排序与名次数值各自明确，保留重要转折的注释 |
| 地理图形案例 | 延续 Fortune 500 案例的“空间锚点＋数量标记＋引线” | RAWGraphs 的注册图表中有二维点与分箱图；实际地图需底图、地理匹配和投影。地理示例详见[案例档案](../02-信息图形类型案例/案例库/CASE-0001-Fortune500都市圈营收分布/README.md) |
| 词云图 | 保留现有语料、词频 CSV、字号公式及最终 SVG，精确排序时加条形图或词频表 | 本期内置图表不含词云，可沿用[第 17 类案例](../02-信息图形类型案例/17-词云图信息可视化.md)的独立流程 |

## 风格参数如何复用

- **准确对比优先。** 同组比较尽量共享基线与尺度。成组数据用同一组颜色，连续量值用有标度的颜色。
- **保留主次。** 主标题说清问题，最大标签放在关键观测附近，其余标签通过索引或局部注释读取。
- **同时留可编辑底稿与展示稿。** RAWGraphs 工程记录数据处理和映射。设计软件里的版面文件记录人工编辑，用核对源确保二者一致。
- **迁移的是方法。** 针对课程、展板和交互原型分别设定字号和尺度，保留现有项目的品牌配色与叙述语气。

可结合[五大数据组织逻辑](../README.md#五种基础组织逻辑)和[17 类表现索引](../02-信息图形类型案例/00-案例索引.md)选择记录位置。原理来源见[图表选择界面](https://github.com/rawgraphs/rawgraphs-app/blob/48c3b2ee9ff412721a2c99c7bed38e734b3fa534/src/components/ChartSelector/ChartSelector.js)与[样式面板](https://github.com/rawgraphs/rawgraphs-app/blob/48c3b2ee9ff412721a2c99c7bed38e734b3fa534/src/components/ChartOptions/ChartOptions.js)。
