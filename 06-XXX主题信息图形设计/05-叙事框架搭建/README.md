# 05｜叙事框架搭建

先明确主叙事，再为每个子主题列出所用字段、关联键和读者要读出的结论。用关键字段组合组织内容，不在底表里把字段拼成一个值。

| 叙事问题 | 字段组合 | 可表达的信息 | 核对条件 |
| --- | --- | --- | --- |
| 这些地点在哪里？ | 名称＋纬度＋经度 | 地图位置和地点标注 | 坐标与地点匹配 |
| 某地 GDP 是多少？ | 地区名称＋GDP 数值＋年份 | 同口径地区比较 | 年份、币种、现价或不变价口径一致 |
| 项目实际主叙事 | | | |

按「主问题 → 总览 → 子主题或案例 → 图注与来源」绘制阅读结构。为每块内容标出使用的字段、图表角色和在版面上的位置。
