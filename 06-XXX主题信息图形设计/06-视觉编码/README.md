# 06｜视觉编码

从第 05 步的字段组合出发，决定什么信息用图形表达、什么信息需要文字说明。

| 编码项 | 设计问题 | 定稿记录 |
| --- | --- | --- |
| 点、线、面、体 | 分别表示对象、关系、区域还是空间结构？哪一项有量化含义？ | |
| 色彩 | 哪些颜色区分类别，哪些明度表示量级，哪些色只用于强调？ | |
| 字体、行距、字距 | 标题、数据标签和解释文字各如何分层？在最终尺寸是否可读？ | |
| 照片、插画与图形 | 用于识别对象、展示证据还是辅助叙事？裁切及图注是否保留关键信息？ | |
| 统计图形 | 坐标、基线、形状、面积与相应数值怎样映射？ | |
| ISO 图形符号与 ISOTYPE | 如用 ISO 标准图形符号，记载适用语义和来源。用 ISOTYPE 做象形统计时，写明每图符单位及分母。 | |

保留配色、网格、标注与图例的版本，检查同一字段在不同分图中的编码是否一致。 [ISOTYPE 基础设计方式](../../03-ISOTYPE信息图/00-ISOTYPE概念与方法.md)
