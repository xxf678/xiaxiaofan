# 信息图形知识库

从案例图拆解数据怎样组织、统计量怎样计算、图形怎样编码，以及读者怎样读完整张图。

以用户提供的《第三讲-信息图形类型学》为本轮核验依据。

## 五种基础组织逻辑

| 逻辑 | 判断问题 |
| --- | --- |
| [编年型](01-信息图形数据逻辑/01-编年型信息图形概念定义.md) | 事件或阶段按什么先后顺序展开？ |
| [层级型](01-信息图形数据逻辑/02-层级型信息图形概念定义.md) | 节点之间是否有上下位、父子或分层关系？ |
| [编目型](01-信息图形数据逻辑/03-编目型信息图形概念定义.md) | 对象按什么属性分组，怎样比较同类条目？ |
| [字母表型](01-信息图形数据逻辑/04-字母表型信息图形概念定义.md) | 读者用什么规范化键查找条目？ |
| [地理图形](01-信息图形数据逻辑/05-地理图形信息图形概念定义.md) | 位置、区域或空间关系是否决定阅读结构？ |

每篇定义依次讨论 A 数据逻辑、B 统计图形与计算、C 视觉编码、D 数据及信息架构、E 视觉叙事架构。混合型、文字／列表型和时间轴型是视觉表现形式，一张图可同时具有基础组织逻辑和一个或多个表现标签。
