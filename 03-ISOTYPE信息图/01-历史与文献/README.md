# 01｜历史与文献

20 世纪 20 年代中期，奥托·纽拉特及其团队在维也纳发展出图像统计方法。团队成员玛丽·赖德迈斯特（后称玛丽·纽拉特）参与把数字和事实转化为可读图形，格尔德·阿恩茨参与图符设计。方法随团队迁往荷兰和英国而发展为 ISOTYPE。 [维也纳大学研究项目](https://isotype.univie.ac.at/en/abstract/)
